# EDA on Retail Sales Data

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset to uncover important patterns, customer behaviour trends, and actionable business insights.

The analysis uses Python and popular data analysis and visualization libraries to understand the dataset and identify meaningful relationships within the data.

## 🎯 Objective

The main objectives of this project are:

- Understand the structure and characteristics of the retail sales dataset.
- Perform data inspection and preprocessing.
- Analyse numerical variables using descriptive statistics.
- Identify monthly and quarterly sales trends.
- Analyse customer demographics such as age groups and gender.
- Identify the top-selling products.
- Analyse revenue by product category.
- Study correlations between numerical variables.
- Generate meaningful business insights from visualizations.

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

### 1. Data Inspection

The dataset was loaded and inspected to understand:

- Number of rows and columns
- Column data types
- Missing values
- Basic dataset structure

### 2. Descriptive Statistics

Descriptive statistics were calculated for numerical columns, including:

- Mean
- Median
- Mode
- Standard deviation

### 3. Time Series Analysis

Monthly and quarterly sales trends were analysed using line charts to understand how sales change over time.

### 4. Customer Demographics Analysis

Customer demographics were explored through:

- Age group distribution
- Gender distribution

### 5. Product Analysis

Product-level analysis was performed to identify:

- Top 10 best-selling products
- Revenue generated by different product categories

Bar charts were used to visualize the results.

### 6. Correlation Analysis

A correlation matrix and heatmap were created to understand relationships between numerical variables.

### 7. Additional Visualization

An additional visualization was created to identify a non-obvious pattern or insight from the retail sales data.

## 💡 Business Insights

The analysis helps identify:

- Sales trends over different time periods.
- Customer demographic patterns.
- Best-performing products.
- High-revenue product categories.
- Relationships between important numerical variables.

These insights can help businesses make better decisions regarding sales, marketing, inventory, and customer targeting.
