# Data Analytics Level 2 - Task 1

## House Price Prediction

### Project Description
This project predicts house prices using Linear Regression.

### Objective
The objective of this project is to build a machine learning model that can predict house prices based on the available housing features.

### Technology Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Machine Learning Algorithm
Linear Regression

### Project File
- `House_Price_Prediction_Linear_Regression.ipynb`

### Steps Performed
1. Loaded the house price dataset.
2. Explored and analyzed the data.
3. Prepared the data for machine learning.
4. Split the data into training and testing sets.
5. Trained a Linear Regression model.
6. Predicted house prices.
7. Evaluated the model performance.

### Conclusion
The Linear Regression model was used to predict house prices from the given dataset.
